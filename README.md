# Compact-Causal-Video-TSE
This repository contains test datasets for this paper - " COMPACT CAUSAL AUDIO-VISUAL TARGET SPEAKER EXTRACTION WITH VISUAL VAD SUPERVISION"

The only publicly available test set, LRS2-2Mix, contains audio-visual discrepancies. For instance, in mixture "6339077953587836416_00025_4.9465_6388126909604862142_00038_-4.9465.wav", both source clips show male speakers (visual), yet the mixture contains a female voice. As a reliable comparison with published results is therefore not possible, we exclude this dataset from our evaluation
